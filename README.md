## What I'm building

- **hunch** — a personal AI agent that lives in your iMessage. Self-hosted and free to run. You text it like a friend, and the part I care about: it texts you first — reminders, follow-ups, the 9am "hey, that landlord email?" nobody asked it to send.
- **[crewline](https://github.com/vibhumaggarwal/crewline)** — a local command center for persistent Claude Code workers. Each worker has a role, explicit permissions, its own git worktree, and memory that survives between sessions.
- **[reelvault](https://github.com/vibhumaggarwal/reelvault)** — store any file or folder inside a video and get it back byte-for-byte. Survives re-encoding. Python + browser.
- **[youtube-sentiment](https://github.com/vibhumaggarwal/youtube-sentiment)** — sentiment analysis of YouTube comments: a Python pipeline plus a web app.
